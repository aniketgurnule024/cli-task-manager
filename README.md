# 🚀 CLI Task Manager

A simple, lightweight command-line task manager built with Python. It allows you to efficiently create, view, complete, and delete tasks directly from your terminal with local file persistence.

## ✨ Features

* **Add Tasks:** Create new tasks with automated ID generation.
* **View Tasks:** List all active and completed tasks in real-time.
* **Track Progress:** Mark tasks as complete as you finish them.
* **Delete Tasks:** Remove unwanted or obsolete tasks.
* **Data Persistence:** Automatically saves your tasks to a local `tasks.txt` file so you never lose your progress.

## 🛠️ Requirements

* Python 3.x installed on your system.
